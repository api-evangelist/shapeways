# Shapeways

> Shapeways is an on-demand 3D printing and additive-manufacturing platform. Its OAuth 2.0 REST API lets applications browse the material catalog, upload and manage 3D models, retrieve shipping options, and place and track manufacturing orders. Base URL: https://api.shapeways.com. Endpoints are versioned with a trailing /v1 path segment.

## APIs

- [Shapeways API reference](https://developers.shapeways.com/api-reference): Materials, Models, Orders, and Cart shipping-options endpoints.
- [Getting started](https://developers.shapeways.com/getting-started): OAuth 2.0 setup, creating an app, first request, placing an order.
- [Manage apps](https://developers.shapeways.com/manage-apps): obtain Client ID and Client Secret.
